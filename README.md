# URL Shortener

Сервис коротких ссылок по образцу [Bitly](https://bitly.com): пользователь сокращает длинный URL,
управляет своими ссылками и смотрит, сколько по ним переходят.

Цель — довести систему до состояния, в котором её можно выкатить реальным пользователям.

## Подход

- **Что делает система** — взято у реального продукта. Функциональность — урезанная часть Bitly:
  только то, что нужно для работающего сервиса, без маркетинговых фич.
- **Как она должна работать** — спроектировано самостоятельно. Нефункциональные требования
  (нагрузка, задержки, доступность, согласованность) намеренно заданы жёсткими,
  чтобы упираться в реальные проблемы: кэширование, репликацию, отказоустойчивость, очереди.
- **Каждое решение записано**: проблема → варианты → выбор → замер. Всё в [`docs/`](docs).

## Запуск

```bash
# 1. Инфраструктура: Postgres, Redis, Kafka
docker compose -f docker/docker-compose.yml up -d

# 2. Сборка
mvn clean install -DskipTests

# 3. Сервисы — в этом порядке
mvn -pl link-service spring-boot:run
mvn -pl redirect-service spring-boot:run
mvn -pl stats-service spring-boot:run
```

## Статус

Работает базовая версия: создание, редирект, статистика кликов.
Сейчас требования пересматриваются по образцу Bitly — аккаунты вместо токена на ссылку,
редактирование ссылок, статистика по времени, защита от вредоносных ссылок.
