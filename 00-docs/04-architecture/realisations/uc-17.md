# Реализация UC-17 Перейти по ссылке

| Что                                       | Кто                  | Как                                                                                                                         | Когда делать |
|-------------------------------------------|----------------------|-----------------------------------------------------------------------------------------------------------------------------|--------------|
| переход засчитывается в статистику        | decode-service       | после редиректа публикует событие клика в `click-events`                                                                    | UC-17        |
| клики превращаются в статистику           | link-service (stats) | consumer читает `click-events` пачками, агрегирует по (код, час), пакетный upsert в `link_stats_hourly`, `_daily`, `_total` | UC-17        |
| почасовые данные старше 90 дней удаляются | link-service (stats) | ночная задача `DELETE ... WHERE hour < now - 90 дней`                                                                       | UC-17        |

Событие клика: `code`, `clickedAt` (UTC).
Публикуется только для засчитываемых переходов: был редирект на адрес назначения (F-11.6) и это не робот (F-11.7).
Страницы «не найдена», «не действует», предупреждения и блокировки событий не порождают.

Offset в Kafka подтверждается только после успешного upsert: при сбое клики перечитываются.
Повторное чтение после сбоя может засчитать часть кликов дважды — допустимо по NFR-6.3.
