# UC-19 Перепроверить ссылки

**Основной актор:** Время
**Заинтересованные лица:** посетители — не попасть на опасный сайт; создатели — их ссылки не блокируют без причины;
сервис — домен не попадает в чёрные списки почтовиков и браузеров
**Требования:** F-10.1 – F-10.12, F-10.15, F-10.17; связи: F-6.5, F-6.6
**Уровень:** цель пользователя

**Цель:** ссылки, которые стали опасными после создания, перестают вести посетителей на опасные сайты.

## Предусловия

- Наступило время проверки ссылки (BR-1).

## Постусловия

**Успех:**

- у ссылки актуальный статус безопасности и причина, если она подозрительная или заблокированная (F-10.15);
- новый статус действует со следующего перехода (F-10.12);
- назначено время следующей проверки (F-10.4).

**Неудача:** статус ссылки не изменился, проверка повторится позже.

## Основной сценарий

1. Наступает время проверки ссылки.
2. Система определяет адрес для проверки: новый адрес, ожидающий проверки (F-6.5), иначе текущий адрес назначения.
3. Система проходит по всем перенаправлениям адреса до конечного (F-10.6).
4. Система сверяет каждый адрес цепочки со своим списком заблокированных доменов и с базами опасных сайтов (F-10.7,
   F-10.9).
5. Система проверяет адреса цепочки по признакам мошенничества: домен зарегистрирован недавно, чужой бренд в домене,
   подменённые буквы, IP вместо домена (F-10.7).
6. Система определяет статус: найден в базах или в своём списке — заблокированная; сработали только признаки —
   подозрительная; иначе — безопасная (F-10.8).
7. Система сохраняет статус и причину и назначает следующую проверку (F-10.4).

## Альтернативные сценарии

**Ожидающий адрес** (шаг 2 взял новый адрес из UC-12)

- **6a.** Новый адрес безопасный → он становится текущим адресом назначения; ссылка ведёт на него (F-6.5).
- **6b.** Новый адрес подозрительный или заблокированный → новый адрес отклоняется, ссылка продолжает вести на старый,
  создатель видит причину отказа (F-6.6). Статус текущего адреса не меняется.

**Опасная ссылка**

- **6c.** Ссылка стала заблокированной → аккаунт создателя больше не может создавать ссылки, все его остальные ссылки
  проверяются вне очереди (F-10.17).

**Сбои проверки**

- **3a.** Адрес не отвечает или перенаправлений слишком много → проверяются адреса, до которых удалось дойти; цепочка,
  которая не заканчивается, — признак мошенничества.
- **4a.** База опасных сайтов недоступна → статус не меняется, проверка повторяется через несколько минут.

**Ссылка изменилась**

- **1a.** Ссылку удалили до проверки → проверка не выполняется, следующая не назначается (F-10.4).

## Бизнес-правила

- **BR-1.** Ссылка подлежит проверке:
    - сразу после создания (F-10.3);
    - сразу после смены адреса назначения (F-10.3);
    - сразу после жалобы посетителя (F-10.5);
    - сразу после обжалования статуса создателем (F-10.16);
    - вне очереди, если у аккаунта появилась заблокированная ссылка (F-10.17);
    - повторно: через 1 час, 1 сутки и 7 дней после создания, дальше раз в месяц (F-10.4).
- **BR-2.** Удалённые ссылки не проверяются; архивные и истёкшие — проверяются: они могут снова начать работать.
- **BR-3.** Пока проверка не прошла, ссылка работает как безопасная (F-10.2).
- **BR-4.** Новый статус действует для уже разосланных ссылок со следующего перехода (F-10.12).
- **BR-5.** Одна ссылка не проверяется одновременно дважды.
