# UC-11 Найти свою ссылку

**Основной актор:** Создатель (пользователь или партнёр)
**Другие акторы:** Внешняя система (от имени создателя, по его API-ключу)
**Сервис:** link-service (аутентификация — gateway)
**Требования:** F-5.1 – F-5.7; связи: F-7.3, F-7.10, F-8, F-10.15, F-11
**Уровень:** цель пользователя

**Цель:** найти свою ссылку в списке и открыть её целиком.

У use case два входа:

- **А. Список** с поиском и фильтрами: `GET /links`;
- **Б. Одна ссылка** целиком: `GET /links/{code}`.

## Предусловия

- Создатель аутентифицирован.

## Постусловия

**Успех:** клиент получил порцию своих ссылок или одну свою ссылку. 

## Основной сценарий А — список

1. Клиент запрашивает `GET /links`, по желанию с поиском, фильтрами, размером порции и курсором.
2. Система аутентифицирует клиента и определяет создателя.
3. Система проверяет параметры.
4. Система выбирает ссылки создателя, подходящие под поиск и фильтры, новые сначала (F-5.1). Удалённые не попадают
   никогда (F-7.10).
5. Система добавляет к каждой ссылке общее число переходов (F-5.3).
6. Система возвращает `200`: порцию ссылок и курсор следующей порции, если она есть (F-5.2).
7. Клиент подгружает следующую порцию, передав курсор, — повтор с шага 1.

## Основной сценарий Б — одна ссылка

1. Клиент запрашивает `GET /links/{code}`.
2. Система аутентифицирует клиента и определяет создателя.
3. Система находит по коду неудалённую ссылку создателя.
4. Система возвращает `200`: все поля ссылки, статус, статус безопасности и его причину (F-5.7, F-10.15). Статистика —
   отдельным запросом (UC-15).

## Альтернативные сценарии

- **2a.** Токен или ключ отсутствует, невалиден или отозван → `401`. Конец.

**Список**

- **3a.** Поисковая строка короче 3 символов → `400`. Конец.
- **3b.** Размер порции меньше 1 или больше 100 → `400`. Конец.
- **3c.** Курсор повреждён или не от этого запроса → `400`. Конец.
- **3d.** `createdFrom` позже `createdTo` → `400`. Конец.
- **4a.** Ничего не найдено → `200`, пустая порция, курсора нет.
- **5a.** Число переходов недоступно → ссылки возвращаются, число переходов пустое. Список не падает из-за статистики.

**Одна ссылка**

- **Б3a.** Ссылки нет, она чужая или удалена → `404` (F-8.2). Конец.

## Параметры списка

| Параметр      | По умолчанию           | Правило                                                              |
|---------------|------------------------|----------------------------------------------------------------------|
| `q`           | —                      | поиск по любой части кода, без учёта регистра, от 3 символов (F-5.5) |
| `status`      | действующие и истёкшие | одно значение: `ACTIVE`, `ARCHIVED`, `EXPIRED` (F-5.4, F-5.6)        |
| `tag`         | —                      | один тег, точное совпадение (F-5.6)                                  |
| `createdFrom` | —                      | момент, включительно                                                 |
| `createdTo`   | —                      | момент, не включительно                                              |
| `limit`       | 50                     | от 1 до 100                                                          |
| `cursor`      | —                      | из ответа на предыдущую порцию                                       |

Все фильтры и поиск сочетаются между собой (F-5.6).

## Бизнес-правила

- **BR-1.** Видны только свои ссылки (F-8).
- **BR-2.** Удалённые не видны никогда; архивные — только с `status=ARCHIVED` (F-5.4).
- **BR-3.** Статус в строке вычисляется: архивная → `ARCHIVED`; действующая по статусу, но с прошедшим сроком →
  `EXPIRED`; иначе `ACTIVE`.
- **BR-4.** Порядок — новые сначала; перейти на произвольную порцию нельзя, только «следующая» (F-5.2).
- **BR-5.** Общее число найденных ссылок не возвращается: список одинаково быстрый для 10 ссылок и для миллионов.
- **BR-6.** Число переходов может отставать на несколько минут (NFR статистики).

## Вход / выход

**Выход А:**

- `items` — ссылки: короткая ссылка, код, заголовок, адрес, теги, дата создания, статус, статус безопасности, число
  переходов (F-5.3);
- `nextCursor` — курсор следующей порции или `null`.

**Выход Б:** ссылка в формате UC-08 плюс `pendingUrl`, `pendingUrlRejection` и причина статуса безопасности.

## Открытые вопросы

- Причины статуса безопасности (F-10.15) ещё нет в модели — появится с UC-19.
- Число переходов (шаг 5) до модуля статистики — заглушка с нулями.
