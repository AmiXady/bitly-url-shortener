# F-3. Лимиты использования

> Система ограничивает, сколько ссылок и запросов может сделать аккаунт за период.
> Это защищает честных пользователей от тех, кто перегружает сервис или рассылает спам.
>
> Акторы: создатель, внешняя система.

## Требования

### Что ограничивается

- **F-3.1** Лимиты одинаковы для всех аккаунтов. Тарифов нет.
- **F-3.2** Создание ссылок — не больше **100 000** в сутки на аккаунт.
  Ссылки из файла (F-5) считаются поштучно.
- **F-3.3** Запросы к API — не больше **600** в минуту на аккаунт, со всех его ключей вместе.
- **F-3.4** Файлы — не больше **3** в обработке одновременно на аккаунт.
- **F-3.5** Неудачные попытки входа — не больше **10** за 15 минут на один email.
  После этого вход для этого email временно закрыт.
- **F-3.6** Лимиты общие для сайта и API: ссылка, созданная через сайт, и ссылка,
  созданная по ключу, тратят один и тот же лимит.

### Превышение лимита

- **F-3.7** Запрос сверх лимита отклоняется ошибкой «лимит превышен»
  с указанием, когда можно повторить.
- **F-3.8** Файл, в котором строк больше, чем осталось в суточном лимите,
  отклоняется **целиком** при загрузке (F-5.5). В ответе указан остаток лимита.
- **F-3.9** Отклонённый по лимиту запрос сам лимит не тратит.

### Видимость

- **F-3.10** Создатель видит в кабинете свои лимиты и сколько уже потрачено.
- **F-3.11** Каждый ответ API сообщает лимит, остаток и время сброса.

## Связи

- F-1 — лимит попыток входа.
- F-2 — запросы по ключу.
- F-4, F-5 — создание ссылок и загрузка файлов.

## Идеи на будущее

- Тарифы с разными лимитами.
- Повышение лимита для отдельного партнёра по запросу.
- Уведомление, когда потрачено 80% лимита.
