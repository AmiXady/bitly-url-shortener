# F-6. Изменение ссылки

> Создатель меняет заголовок, теги, срок жизни и адрес назначения — например,
> чтобы исправить ошибку после рассылки или продлить истёкшую ссылку.
> Сама короткая ссылка при этом не меняется.
>
> Акторы: создатель, внешняя система (по API-ключу).

## Требования

### Что можно менять

- **F-6.1** Создатель может изменить заголовок и теги — по тем же правилам, что при создании (F-3.3).
- **F-6.2** Создатель может изменить срок жизни: задать, перенести или убрать —
  тогда ссылка становится бессрочной. Новый срок — не раньше чем через 5 минут
  от момента изменения (F-3.19).
- **F-6.3** Создатель может изменить адрес назначения. Новый URL проходит ту же проверку,
  что при создании (F-3.9, F-3.10).
- **F-6.4** Код ссылки изменить нельзя (F-3.18).

### Смена адреса назначения

- **F-6.5** Пока новый адрес проверяется на безопасность (F-10), ссылка ведёт на **старый** адрес.
- **F-6.6** Если новый адрес признан опасным, изменение отклоняется, ссылка продолжает
  вести на старый адрес. Создатель видит причину отказа.
- **F-6.7** Статистика после смены адреса **не сбрасывается**: переходы считаются
  для ссылки, а не для адреса.
- **F-6.8** Если адрес меняют снова, пока предыдущий новый адрес ещё проверяется,
  предыдущий отменяется и проверяется последний.

### Ограничения

- **F-6.9** Изменить можно только свою ссылку (F-8).
- **F-6.10** Что можно менять, зависит от состояния ссылки:
    - **действующую** — всё из F-6.1 – F-6.3;
    - **истёкшую** — только срок жизни: продлить или сделать бессрочной.
      После этого ссылка снова действует. Так ссылку с напечатанным кодом
      можно оживить — её код всё равно никогда не освобождается (F-3.21);
    - **архивную** — ничего: сначала её возвращают из архива (F-7.4);
    - **удалённую** — ничего (F-7.8).

## Связи

- F-3 — правила для заголовка, тегов, срока жизни и URL.
- F-7 — архивную ссылку сначала возвращают из архива, удалённую изменить нельзя.
- F-8 — изменить можно только свою ссылку.
- F-9 — изменения действуют при следующем переходе.
- F-10 — новый адрес проверяется на безопасность.
- F-11 — статистика после смены адреса сохраняется.

## Идеи на будущее

- История изменений адреса назначения.
- Статистика отдельно по каждому адресу назначения.
