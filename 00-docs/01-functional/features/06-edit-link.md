# F-6. Изменение ссылки

> Создатель меняет заголовок, теги, срок жизни и адрес назначения — например,
> чтобы исправить ошибку после рассылки. Сама короткая ссылка при этом не меняется.
>
> Акторы: создатель, внешняя система (по API-ключу).

## Требования

### Что можно менять

- **F-6.1** Создатель может изменить заголовок и теги — по тем же правилам, что при создании (F-3).
- **F-6.2** Создатель может изменить срок жизни: задать, перенести или убрать —
  тогда ссылка становится бессрочной.
- **F-6.3** Создатель может изменить адрес назначения. Новый URL проходит ту же проверку,
  что при создании (F-3).
- **F-6.4** Код ссылки изменить нельзя (F-3.18).

### Смена адреса назначения

- **F-6.5** Пока новый адрес проверяется на безопасность (F-10), ссылка ведёт на **старый** адрес.
- **F-6.6** Если новый адрес признан опасным, изменение отклоняется, ссылка продолжает
  вести на старый адрес. Создатель видит причину отказа.
- **F-6.7** Статистика после смены адреса **не сбрасывается**: переходы считаются
  для ссылки, а не для адреса.

### Ограничения

- **F-6.8** Изменить можно только **активную** ссылку. Архивную, истёкшую
  и удалённую изменить нельзя.
- **F-6.9** Изменить можно только свою ссылку (F-8).


## Идеи на будущее

- История изменений адреса назначения.
- Статистика отдельно по каждому адресу назначения.
