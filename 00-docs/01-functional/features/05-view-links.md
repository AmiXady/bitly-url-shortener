# F-5. Просмотр своих ссылок

> Создатель видит все свои ссылки, ищет и фильтрует их, открывает одну ссылку целиком.
>
> Акторы: создатель, внешняя система (по API-ключу).

## Требования

### Список

- **F-5.1** Создатель видит список своих ссылок, **новые сначала**.
- **F-5.2** Список отдаётся частями: создатель видит первую часть и подгружает следующую
  («показать ещё»). Перейти сразу на произвольную страницу нельзя.
- **F-5.3** В строке списка: короткая ссылка, заголовок, адрес назначения, теги, дата создания,
  статус (активная, архивная, истёкшая), статус безопасности и **общее число переходов**.
- **F-5.4** Архивные ссылки по умолчанию не показываются (F-7.3), удалённые — никогда (F-7.10).

### Поиск и фильтры

- **F-5.5** Поиск по **коду** ссылки.
- **F-5.6** Фильтры: по тегу, по статусу (активные, архивные, истёкшие), по дате создания.
  Фильтры можно сочетать между собой и с поиском.

### Одна ссылка

- **F-5.7** Создатель может открыть одну свою ссылку и увидеть все её поля, статус безопасности
  с причиной (F-10.15) и статистику (F-11).

## Связи

- F-7 — архивные и удалённые ссылки в списке.
- F-8 — видны только свои ссылки.
- F-10 — статус безопасности.
- F-11 — число переходов и статистика.

## Идеи на будущее

- Поиск по заголовку и адресу назначения.
- Другие сортировки: старые сначала, по заголовку, по числу переходов.
