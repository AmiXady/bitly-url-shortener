# F-8. Изоляция данных владельца

> Создатель видит и меняет только свои ссылки и их статистику. Чужие ссылки для него
> неотличимы от несуществующих.
>
> Акторы: создатель, внешняя система (по API-ключу).

## Требования

- **F-8.1** Создатель имеет доступ только к своим данным:
    - ссылкам — просмотр, изменение, архив, удаление (F-5, F-6, F-7);
    - статистике ссылок (F-11);
    - загрузкам файлов и их результатам (F-4);
    - своим API-ключам (F-2).
- **F-8.2** Запрос к чужим данным получает **тот же ответ**, что и запрос к несуществующим:
  «не найдено». По ответу нельзя понять, существует ли чужая ссылка.
- **F-8.3** API-ключ даёт доступ только к данным аккаунта, которому он принадлежит.
- **F-8.4** Переход по короткой ссылке (F-9) доступен всем — изоляция касается только управления.

## Связи

- F-2 — доступ по ключу.
- F-4, F-5, F-6, F-7, F-11 — где действует правило.
- F-9 — переход по ссылке публичный.
