# F-4. Массовое сокращение

> Создатель загружает CSV-файл с длинными ссылками — например, персональные ссылки
> для рассылки по тысячам покупателей. Система обрабатывает файл в фоне и отдаёт
> файл-результат с короткими ссылками. Ошибка в одной строке не мешает создать остальные.
>
> Акторы: создатель (через сайт), внешняя система (по API-ключу).

## Требования

### Загрузка

- **F-4.1** Создатель загружает CSV-файл на сайте или по API-ключу.
- **F-4.2** Формат файла: CSV в UTF-8, первая строка — заголовки. Колонки:
    - `url` — обязательная;
    - `title`, `tags` (через `;`), `code`, `expires_at` — необязательные, по правилам F-3.
- **F-4.3** На сайте можно скачать шаблон файла с правильными заголовками.
- **F-4.4** В файле — не больше **100 000** строк.
- **F-4.5** Файл отклоняется **целиком** сразу при загрузке, если:
    - он пустой или это не CSV;
    - заголовки не совпадают с шаблоном;
    - строк больше 100 000;
    - строк больше, чем осталось в суточном лимите создателя (F-13).

### Обработка

- **F-4.6** Файл обрабатывается в фоне. Сразу после загрузки создатель получает номер загрузки.
- **F-4.7** Каждая строка проверяется и создаётся по правилам F-3.
- **F-4.8** Ошибка в строке не останавливает обработку: строка пропускается,
  причина попадает в результат.
- **F-4.9** Если свой код из строки уже занят, ссылка всё равно создаётся —
  со сгенерированным кодом, а в результате это отмечено.
- **F-4.10** Одинаковые URL без своего кода получают одну и ту же ссылку (F-3.5) —
  и внутри файла, и при повторной загрузке того же файла.

### Статус и результат

- **F-4.11** У загрузки есть статус: в очереди, обрабатывается (сколько строк готово из скольких),
  готово, готово с ошибками, отклонено.
- **F-4.12** Когда обработка закончилась, создателю приходит письмо на email.
- **F-4.13** Результат — файл для скачивания: исходные строки и колонки
  `short_url`, `status`, `error_message`.
- **F-4.14** Создатель видит список своих загрузок со статусами.
  Файл-результат можно скачать в течение **30 дней**.

## Связи

- F-2 — загрузка и скачивание результата по API-ключу.
- F-13 — строки файла тратят суточный лимит, число файлов в обработке ограничено.
- F-3 — правила для каждой строки.

## Идеи на будущее

- Пачка ссылок в JSON через API без файла.
- Файлы Excel (XLSX).
- Отмена обработки загруженного файла.
