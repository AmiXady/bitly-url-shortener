# F-2. Доступ к API по ключу

> Создатель выпускает ключи для своих программ — например, для сервера магазина,
> который сам создаёт ссылки для рассылок. Программа с ключом работает от имени
> создателя: всё, что она создаёт, принадлежит его аккаунту.
> Ключей может быть несколько, любой можно отозвать, не трогая остальные.
>
> Акторы: создатель (выпускает и отзывает ключи), внешняя система (пользуется ключом).

## Требования

### Выпуск ключа

- **F-2.1** Создатель выпускает ключ в личном кабинете после входа по паролю.
- **F-2.2** Выпустить ключ можно только с подтверждённым email (F-1.5).
- **F-2.3** При выпуске создатель даёт ключу название, например «Сервер магазина»,
  чтобы различать ключи.
- **F-2.4** Ключ показывается целиком **один раз** — сразу после выпуска.
  Потом увидеть его снова нельзя, только выпустить новый.
- **F-2.5** У аккаунта может быть не больше **10** действующих ключей.

### Просмотр и отзыв

- **F-2.6** Создатель видит список своих ключей: название, первые символы ключа,
  дату создания и когда ключ использовался последний раз.
- **F-2.7** Создатель может отозвать любой ключ. После отзыва запросы с этим ключом
  отклоняются. Отзыв необратим.
- **F-2.8** Отзыв одного ключа не влияет на остальные ключи и на вход по паролю.
- **F-2.9** Смена или восстановление пароля **не отзывают** ключи — иначе сломаются
  интеграции создателя.

### Работа по ключу

- **F-2.10** Запрос с ключом выполняется от имени владельца ключа: ссылки создаются
  в его аккаунте, доступны все его ссылки и их статистика.
- **F-2.11** По ключу нельзя управлять аккаунтом: выпускать и отзывать ключи,
  менять пароль. Это только после входа по паролю.
- **F-2.12** Запрос без ключа, с несуществующим или отозванным ключом отклоняется
  одной и той же ошибкой «не авторизован».

## Связи

- F-1 — ключ выпускает только зарегистрированный создатель с подтверждённым email.
- F-4 – F-10, F-13 — всё, что создатель делает со ссылками и статистикой, доступно и по ключу.

## Идеи на будущее

- Срок действия ключа.
- Права ключа: например, только чтение статистики.
- Переименование ключа.
