# F-4. Сокращение ссылки

> Создатель отправляет длинный URL и получает короткую ссылку. Можно задать свой код,
> заголовок, теги и срок жизни. Система проверяет, что URL корректный.
>
> Здесь — создание **одной** ссылки. Эти же правила действуют для каждой ссылки в пачке (F-5).
>
> Акторы: создатель, внешняя система.

## Требования

### Создание

- **F-4.1** Создатель отправляет длинный URL и получает короткую ссылку вида `https://sho.rt/{код}`.
- **F-4.2** Ссылка создаётся в аккаунте создателя и принадлежит ему.
- **F-4.3** Необязательные поля при создании:
    - **свой код** (F-4.14);
    - **заголовок** — до 200 символов;
    - **теги** — до 10 на ссылку, каждый до 50 символов;
    - **срок жизни** (F-4.19).
- **F-4.4** В ответе — короткая ссылка, её код и все сохранённые поля.

### Повторное сокращение

- **F-4.5** Если у создателя уже есть действующая ссылка на тот же URL, созданная
  без своего кода, и в запросе своего кода нет — возвращается **эта ссылка**, новая не создаётся.
  Заголовок, теги и срок жизни из нового запроса при этом не применяются.
- **F-4.6** Запрос со своим кодом всегда создаёт новую ссылку.
- **F-4.7** Ссылки разных создателей независимы: одинаковый URL у двух аккаунтов — две разные ссылки.
- **F-4.8** Истёкшие и удалённые ссылки при повторном сокращении не учитываются —
  создаётся новая.

### Проверка URL

- **F-4.9** URL должен быть корректным: схема `http` или `https`, есть домен,
  длина до 2048 символов.
- **F-4.10** Нельзя сократить ссылку на сам `sho.rt` — иначе возможны петли редиректов.
- **F-4.11** Ссылки на другие сервисы сокращения разрешены.
- **F-4.12** Некорректный URL → ошибка с понятным описанием причины.

### Код

- **F-4.13** Сгенерированный код — **7 символов**: строчная латиница и цифры
  без путающихся символов (`0`, `o`, `1`, `l`, `i`).
- **F-4.14** Свой код — от **3 до 30** символов: латиница, цифры, `-`, `_`.
- **F-4.15** Регистр в коде **важен**: `sho.rt/Sale` и `sho.rt/sale` — разные ссылки.
- **F-4.16** Свой код уже занят → ошибка, создатель выбирает другой.
- **F-4.17** Нельзя занять служебные пути, например `api`, — без учёта регистра:
  `API` и `Api` тоже запрещены.
- **F-4.18** Код ссылки после создания изменить нельзя: его уже могли напечатать или разослать.

### Срок жизни

- **F-4.19** Срок жизни задаётся датой и временем истечения — не раньше чем
  через **5 минут** после создания.
- **F-4.20** Без срока ссылка бессрочная.

## Связи

- F-1 — создавать ссылки можно только с подтверждённым email.
- F-3 — каждая созданная ссылка тратит суточный лимит.
- F-5 — пачка применяет эти правила к каждой ссылке.
- F-9 — когда код удалённой ссылки освобождается.
- F-12 — каждый URL проверяется на безопасность.

## Идеи на будущее

- Срок жизни числом дней.
- Свой код с кириллицей.


- **F-3.17** Если свой код уже занят ссылкой **этого же создателя на тот же URL** —
  возвращается эта ссылка, а не ошибка. Так повтор запроса после сбоя сети
  не превращается в ошибку.
