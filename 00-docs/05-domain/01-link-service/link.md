# Link

Короткая ссылка. Сервис: link-service. Хранение: Postgres.

## Поля

| Поле         | Тип                   | Обязательно | Правило                                                          |
|--------------|-----------------------|-------------|------------------------------------------------------------------|
| id           | UUID                  | да          | технический ключ                                                 |
| code         | string(30)            | да          | уникален глобально, регистр важен (F-3.15), не меняется (F-3.18) |
| customCode   | boolean               | да          | true, если код задал клиент; нужен для дедупликации (F-3.5)      |
| url          | string(2048)          | да          | адрес назначения (F-3.9)                                         |
| ownerId      | UUID                  | да          | владелец (F-3.2)                                                 |
| title        | string(200)           | нет         | F-3.3                                                            |
| tags         | list<string(50)>, ≤10 | нет         | F-3.3                                                            |
| expiresAt    | timestamp             | нет         | ≥ createdAt + 5 мин (F-3.19), null — бессрочная (F-3.20)         |
| status       | enum                  | да          | ACTIVE                                                           |
| safetyStatus | enum                  | да          | NOT_CHECKED, SAFE, SUSPICIOUS, BLOCKED (F-10.1)                  |
| createdAt    | timestamp             | да          |                                                                  |

## Инварианты

- `code` не меняется после создания.
- Действующая ссылка — `status = ACTIVE` и (`expiresAt` пустой или в будущем).
  Истечение вычисляется, а не хранится статусом.
- Новая ссылка создаётся с `safetyStatus = NOT_CHECKED` (F-10.2).
