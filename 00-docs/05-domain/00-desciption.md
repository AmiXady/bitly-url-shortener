# Доменная модель

Здесь описаны модели системы. Я определяю их из use cases: детализирую сценарий,
выделяю из него понятия и добавляю только то, что нужно этому use case.

Модели разложены по сервисам — у каждого сервиса своя модель.
Один файл на модель: поля, правила, где хранится и какой use case её добавил.
